# burstsim-engine — обвязка сборки движка

Здесь **нет исходников SimulationCraft** и никогда не будет. Это решение, а не упущение: полная история апстрима весит около 5 ГБ, а наших правок в движке ноль и быть не должно. Репозиторий содержит только то, что принадлежит нам, — скрипты сборки, прогонщик канареек и **закреплённый коммит апстрима**, на котором собирается текущая версия. Обоснование: ADR-0011 в репозитории `burstsim`.

Следствие, ради которого всё и затевалось: **обновление движка — это смена одного числа** в `upstream.json`. Конфликтов слияния не бывает по построению, а не по дисциплине.

## Состав

| Файл | Что это |
|---|---|
| `upstream.json` | Закреплённый SHA апстрима, ветка, список патчей (сейчас пустой) |
| `scripts/sync-upstream.sh` | Приводит рабочую копию simc к закреплённому SHA; `--latest` показывает, что приехало |
| `scripts/build-wasm.sh` | Сборка WASM через Emscripten |
| `scripts/smoke-test.mjs` | Один эталонный профиль — «сборка вообще считает» |
| `scripts/canary.mjs` | Двенадцать профилей по ролям, сравнение с базовой линией |
| `canary-baseline.json` | Зафиксированное «до». Без него патч-день не даёт информации |

## Как собрать

```bash
export SIMC_DIR=/e/simc          # где лежит рабочая копия апстрима
./scripts/sync-upstream.sh       # клонирует или переставляет на закреплённый SHA
source /e/emsdk/emsdk_env.sh
./scripts/build-wasm.sh
node scripts/smoke-test.mjs
node scripts/canary.mjs
```

Нужен Emscripten (проверено на 6.0.3), CMake и Ninja.

## Что известно про сборку

- **Однопоточный путь не собирается.** `SC_NO_THREADING=ON` на ветке `midnight` разваливает подсистему profileset — ядро Top Gear и Droptimizer. Рабочая сборка многопоточная (`-pthread`), число потоков задаётся в рантайме. Флаг `--single` оставлен только для перепроверки после обновления апстрима.
- **Четыре профиля из двенадцати аварийно завершают WASM-сборку**: Death Knight Blood, Mage Frost, Priest Shadow, Evoker Devastation. Профиль разбирается нормально, симуляция стартует и падает в процессе счёта; от числа потоков не зависит. Крашится ли на тех же профилях native — **неизвестно**: native-сборка пока заблокирована.
- **Сверка WASM с native не выполнена.** Пока её нет, браузерный лейн публиковать нельзя.

## Лицензия

Скрипты в этом репозитории — наши. Собираемый ими SimulationCraft распространяется под **GPL v3**; при раздаче собранного WASM пользователям соответствующий исходный код — это апстрим на закреплённом SHA плюс всё содержимое этого репозитория.
